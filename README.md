# Humanismehelt 🌈

Et lite, dysleksivennlig læringsspill på norsk om humanisme og sentrale fagbegreper. Laget for ungdomsskoleelever.

## Spill og lær
- **Lær:** snu flashcards og marker begreper du kan.
- **Quiz:** øv på å velge riktig forklaring, med poeng og tilbakemelding.
- **Match:** koble fagbegrep til riktig forklaring.
- **Alle begrep:** bla gjennom hele ordlisten.

Framgang og poeng lagres lokalt i nettleseren. Ingen konto eller installasjon er nødvendig. Åpne `index.html` i en nettleser, eller publiser repoet med GitHub Pages.

## Tilgjengelighet
Tydelig sans-serif tekst, luftig linjeavstand, korte forklaringer, tastaturbetjening av flashkort, synlig fokus, tekstlige tilbakemeldinger og støtte for redusert bevegelse. Regnbuefargene er brukt som dekor og ikke som eneste måte å formidle informasjon på. Lyd er valgfritt og av som standard.
